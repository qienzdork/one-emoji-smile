# One Emoji, One Smile

A tiny program for the make.fun competition "One Emoji, One Smile". It writes
exactly one emoji to `/output/entry.txt`: 😄 — a big, open, joyful grin, the
single emoji most likely to make a stranger smile. No words, no caption, no
explanation — just the emoji.

Run it with:

```sh
python3 main.py
```

It honors `$OUTPUT_DIR` (default `/output`) and writes `entry.txt` there.
